    Claude Code & Cursor

    Reuse the method, adapt the host

    The procedures are reusable; Copilot configuration is not automatically portable. These are adaptation steps, not tested cross-host installations.

    Claude Code

    1. Merge safety and routing instructions into a root CLAUDE.md. Reference the canonical method and agent body under .github/; do not reuse Copilot frontmatter as Claude settings.
    2. For native discovery, adapt complete skill folders into .claude/skills/. Preserve assets and repair relative links and script paths.
    3. Configure trusted MCP servers and permissions in Claude. Adapt save-case/retro into native skills, or request their procedures in chat.

    Cursor

    1. Merge the same instructions into root AGENTS.md or a .cursor/rules/*.mdc rule. Include mandatory safety rules directly.
    2. Adapt complete skill folders into .cursor/skills/ or .agents/skills/. Check frontmatter, relative links and commands.
    3. Configure Cursor MCP and approval settings; verify actual tool names instead of copying the Copilot allowlist.

    Validate before connecting

    Ask for query triage with the exact request missing: no Azure calls, secret reads or writes. Confirm the workflow, missing evidence, hypotheses and stop for approval. Then check skill loading and tool discovery before approving a scoped read.

    UAT/PROD and unknown environments stay read-only. Keep least privilege and evidence requirements. Instructions alone do not enforce permissions.
